# Larp-Exodus

A balance editor. Everything runs from `balance-editor.exe`.

## Download

➡️ **[Download the latest version](https://github.com/lasettaja12/Larp-Exodus/releases/latest)** and grab `larpxodus.rar` from the **Assets** section.

## How to use

1. Download `larpxodus.rar`.
2. Extract it with [WinRAR](https://www.win-rar.com/) or [7-Zip](https://www.7-zip.org/).
3. Run **`balance-editor.exe`** from the extracted folder.

No installation needed. Windows only.
